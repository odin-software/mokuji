# v0.6 — landing pública

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Servir una landing pública en `/` para visitantes deslogueados (en vez del redirect actual a `/auth`), portando el diseño del handoff Claude Design (`dx-marketing.jsx` + `dx-marketing-more.jsx`) a una página responsive con default OG card. Cerrar el minor con tag `v0.6.0`.

**Architecture:** Una única plantilla `landing.html` (mobile-first + breakpoint desktop a 1024px) sirve a usuarios sin sesión desde el mismo `home.Handler`. Estilos específicos del landing en un `<style>` scoped dentro del template, reusando los tokens CSS custom properties ya definidos en `layout.html`. Default OG card sirve PNG estático exportado del design canvas a `web/static/og/og-default.png`.

**Tech Stack:** Go stdlib (`net/http`, `html/template`, `database/sql`), SQLite, sin frameworks. Templates server-rendered, CSS plano, JS vanilla mínimo.

**Spec de referencia:** [docs/superpowers/specs/2026-05-24-mokuji-v1.0-design.md](../specs/2026-05-24-mokuji-v1.0-design.md) — sección "v0.6 — landing".

**Pre-condición:** Library ordering ya está cerrado en commit `3b55589` (verificable con `git log --oneline | grep "biblioteca"`). Este plan cubre el resto del minor.

- [ ] **Step 3: Modificar el handler para renderizar landing en unauth + agregar hero placeholder mínimo**

En `internal/home/home.go`, reemplazar la función `home` completa (líneas 78-122 aprox):

```go
func (h *Handler) home(w http.ResponseWriter, r *http.Request) {
	s, ok := session.FromContext(r.Context())
	if !ok {
		// Visitante sin sesión: servir la landing pública.
		w.Header().Set("Content-Type", "text/html; charset=utf-8")
		if err := h.tmpl.ExecuteTemplate(w, "layout", landingData{}); err != nil {
			h.logger.Error("renderizar landing", "err", err)
		}
		return
	}

	var emailAddr string
	var slug sql.NullString
	err := h.db.QueryRowContext(r.Context(),
		`SELECT email, slug FROM users WHERE id = ?`, s.UserID,
	).Scan(&emailAddr, &slug)
	if err != nil {
		h.logger.Error("cargar email de usuario", "user_id", s.UserID, "err", err)
		http.Error(w, "internal error", http.StatusInternalServerError)
		return
	}

	var releases []releaseshandler.Release
	if h.releases != nil {
		releases, err = h.releases.UnreadReleases(r.Context(), s.UserID, HomeWidgetReleases)
		if err != nil {
			h.logger.Error("cargar widget releases", "user_id", s.UserID, "err", err)
			releases = nil
		}
	}

	w.Header().Set("Content-Type", "text/html; charset=utf-8")
	if err := h.tmpl.ExecuteTemplate(w, "layout", homeData{
		Email:       emailAddr,
		Username:    slug.String,
		Session:     s,
		Releases:    releases,
		HasUsername: slug.Valid,
	}); err != nil {
		h.logger.Error("renderizar home", "err", err)
	}
}

// landingData es el payload del template landing.html para visitantes
// sin sesión. Por ahora no requiere campos (la landing es estática), pero
// el tipo está acá para que crecer (ej. counters dinámicos) sea trivial.
type landingData struct{}
```

CRÍTICO: el template renderizado en unauth debe ser `layout` con el bloque `content` proveniente de `landing.html` (no `home.html`). `html/template` resuelve esto por **el último bloque parseado con el mismo nombre** — el orden actual es `layout, home, landing`, lo que significa que `landing.html` overrideó a `home.html`. **Necesitamos invocar el template correcto explícitamente o aislar los blocks.**

Solución: renombrar los blocks de cada hoja y tener `layout.html` con dos slots distintos NO es viable sin un refactor mayor. La solución limpia es **parsear dos `*template.Template` separados** en `New()`:

Reemplazar el bloque ParseFS (líneas 60-66) por:

```go
	tmplDashboard, err := template.New("base").Funcs(funcs).ParseFS(
		cfg.HTMLTemplates, "layout.html", "home.html",
	)
	if err != nil {
		return nil, fmt.Errorf("parsear templates dashboard: %w", err)
	}
	tmplLanding, err := template.New("base").Funcs(funcs).ParseFS(
		cfg.HTMLTemplates, "layout.html", "landing.html",
	)
	if err != nil {
		return nil, fmt.Errorf("parsear templates landing: %w", err)
	}

	return &Handler{
		db:          cfg.DB,
		tmpl:        tmplDashboard,
		tmplLanding: tmplLanding,
		releases:    cfg.Releases,
		logger:      cfg.Logger,
	}, nil
```

Y agregar `tmplLanding` al struct `Handler`:

```go
type Handler struct {
	db          *sql.DB
	tmpl        *template.Template
	tmplLanding *template.Template
	releases    ReleasesProvider

}
```

```go

```

