## Convenciones de la documentación

- Español por defecto. Inglés solo para términos técnicos sin buena traducción.
- Filenames sin acentos, contenido con acentos.
- ADRs son **inmutables** una vez aceptadas. Si una decisión cambia, se escribe ADR nueva que la reemplaza; la vieja se marca como `Reemplazada por NNNN` y se conserva como historia.
- Documentos vivos (como `decisiones-pendientes.md`) se editan según evoluciona el proyecto.
